# PR 템플릿 (한국어)

한국어 프로젝트에 사용한다. 모든 섹션을 채우고, 해당 없는 항목은 "해당 없음"으로 적는다.

## 제목

`<type>: <변경 요약, 70자 이내>` — 예: `fix: PromptInput 빈 입력 처리`

## 본문

```markdown
## 요약
<!-- 이 PR이 무엇을, 왜 바꾸는지 1~3문장. diff 나열이 아니라 의도 중심으로. -->

## 변경 사항
<!-- 주요 변경을 영역별로 불릿으로 정리. -->
-

## 배경 / 관련 이슈
<!-- 왜 필요한지. 이슈 링크. 자동 종료는 "Closes #123". -->

## 테스트 방법
<!-- 리뷰어가 따라 할 수 있는 검증 절차와 명령어. -->
1.

## 체크리스트
- [ ] 테스트 추가·수정 (해당 없으면 사유 기재)
- [ ] 기존 테스트 로컬 통과
- [ ] 문서 갱신 (해당 없음 가능)
- [ ] 호환성을 깨는 변경 없음 (있으면 아래에 기재)

## 호환성 영향
<!-- 영향 범위와 마이그레이션 방법. 없으면 "없음". -->

## 스크린샷 / 리뷰어 참고
<!-- UI 변경은 전/후 이미지. 중점적으로 봐줬으면 하는 부분. 없으면 "해당 없음". -->
```
