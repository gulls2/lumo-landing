# Agent Guide — Server

`Server/` 폴더에서 작업하는 AI 에이전트를 위한 안내서. 루트의 `agent.md`·`CLAUDE.md` 규칙도 함께 따른다.

## 현재 상태
- 이 폴더는 아직 비어 있다. 서버 코드·런타임·프레임워크는 정해지지 않았다.
- 랜딩페이지(`../index.html`)는 정적 단일 파일이며 서버에 의존하지 않는다.

## 작업 원칙
- 서버 코드는 이 폴더 안에만 둔다. 루트의 `index.html`은 요청 없이 수정하지 않는다.
- 런타임·프레임워크·패키지는 임의로 정하지 않고, 필요하면 먼저 사용자에게 확인한다.
- 요청받은 범위만 구현하고, 요청하지 않은 엔드포인트·기능은 추가하지 않는다.

## 보안
- API 키, 비밀번호, 토큰, DB 접속 문자열은 코드·문서·로그에 넣지 않는다. 환경변수나 `.env`(커밋 제외)로 분리한다.
- 개인정보(주민번호, 연락처 목록 등)를 샘플 데이터로도 쓰지 않는다. 더미 값만 쓴다.
